# Imagens do Compredahorta

Adicione as seguintes imagens nesta pasta:

## Estrutura de Arquivos

```
compredahorta/
├── dashboard-admin.png          # Dashboard administrativo principal
├── dashboard-analytics.png      # Dashboard com analytics e métricas
├── produtos-admin.png            # Tela de gestão de produtos
├── transporte-admin.png         # Tela de gestão de transporte
├── dashboard-mobile.png         # Dashboard versão mobile
├── loja-home.png                # Loja - Página inicial
├── loja-produtos.png            # Loja - Catálogo de produtos
├── loja-carrinho.png            # Loja - Carrinho de compras
└── pedidos.png                  # Tela de gestão de pedidos
```

## Nomes das Imagens

1. **dashboard-admin.png** - Dashboard administrativo com métricas gerais
2. **dashboard-analytics.png** - Dashboard com gráficos e analytics
3. **produtos-admin.png** - Tela administrativa de gestão de produtos
4. **transporte-admin.png** - Tela de gestão de pedidos em transporte
5. **dashboard-mobile.png** - Dashboard versão mobile
6. **loja-home.png** - Loja virtual - página inicial
7. **loja-produtos.png** - Loja virtual - catálogo de produtos
8. **loja-carrinho.png** - Loja virtual - carrinho de compras
9. **pedidos.png** - Tela de gestão de pedidos

## Formato Recomendado

- **Formato**: PNG ou JPG
- **Resolução**: Mínimo 1920x1080px (Full HD)
- **Tamanho**: Máximo 2MB por imagem
- **Qualidade**: Alta qualidade para melhor visualização

## Dados Sensíveis

⚠️ **IMPORTANTE**: Antes de adicionar as imagens, certifique-se de:

- ✅ Sensurar nomes de pessoas
- ✅ Sensurar valores monetários
- ✅ Sensurar endereços completos
- ✅ Sensurar números de telefone
- ✅ Sensurar emails pessoais
- ✅ Sensurar informações de clientes

Use ferramentas de edição de imagem para aplicar blur ou substituir por dados fictícios.
